## Summary
O2P2 is an object-factorized learned world model trained only from images, using segments as the sole supervision and no object-property labels. It has three jointly trained modules:
- a perception module that maps each segment to a latent object vector;
- a physics module made of pairwise-interaction and unary-transition MLPs;
- a renderer that composes per-object images using predicted heatmaps.

The physics module predicts the steady state of the scene after a block is dropped. A CEM planner then uses the latent object space to build block towers matching a goal image, including on a real Sawyer arm.

## 3. Datasets
- **Training data:** 60,000 MuJoCo images. Each scene shows a block dropped onto a platform holding up to 4 other blocks (cubes, cuboids, triangles; varied colour and pose). Only the initial and final frames are used, with ground-truth segments. The data can be regenerated with the repo scripts.
- **Real-robot data:** a small set of Sawyer images, with the gripper holding each object at 100 positions, used to train an action embedder. Not released.

## 4. Evaluation and downstream tasks
- **Image reconstruction and steady-state prediction:** qualitative only (Fig. 3).
- **Simulated tower building (Table 1, % correct builds):**

  | Method | Correct builds (%) |
  |---|---|
  | No-physics ablation | 0 |
  | SAVP video-prediction model | 24 |
  | **O2P2** | **76** |
  | Oracle using MuJoCo, pixel cost | 71 |
  | Oracle using MuJoCo, object-level cost | 92 |

- **Real Sawyer arm:** 17 of 25 goal towers built correctly (Sec. 3.4).
- **Alternate goals (qualitative):** maximize tower height; stabilize a floating block.
- **Downstream task:** model-based planning (CEM) for block stacking.

## 5. Architecture and techniques
- **Perception:** a 4-layer CNN encoder, applied to each segment separately.
- **Physics:** ō_k = f_trans(o_k) + Σ_{j≠k} f_interact(o_k, o_j) + o_k, with both functions as 2-layer MLPs. It makes a single prediction of the final, settled configuration rather than per-timestep rollouts.
- **Renderer:** two convolutional decoders, one producing a per-object image and one a heatmap. The composite image is a heatmap-weighted average of the object images, acting as a learned depth ordering.
- **Training loss:** L2 plus VGG perceptual loss on the reconstruction of I0 and the prediction of I1.
- **Planning:** CEM with 5 iterations, 1,000 samples per iteration and a 10% elite set. The cost is L2 distance in latent object space to the nearest goal object.
- **Real-robot changes:** an embedder MLP maps actions directly to object vectors, and pixel losses are added to the cost.

## 6. Conclusions and future work
- **Authors' conclusions:** object factorization learned without property supervision gives representations that support planning in configurations unseen during training. O2P2 outperforms object-agnostic pixel-space approaches.
- **Own observations:**
  - The physics module predicts only the final steady state, so it is not a temporal rollout model.
  - The domain is narrow: simple blocks in simulation, with ground-truth segments at training time.
  - Only data-generation code is public.
  - It is pre-Stanford work. It is included because Wu is the last author and the paper is a top-venue world-model-for-planning paper.
