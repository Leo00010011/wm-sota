## Summary
The paper learns a compositional Koopman world model. A graph neural network encodes each object into a Koopman embedding in which dynamics are linear. The Koopman and control matrices are block-structured and shared across object pairs of the same relation type. Because system identification reduces to least squares and control reduces to a quadratic program, the model adapts quickly to unknown physical parameters and to systems with a variable number of objects (ropes, soft robots).

## 3. Datasets
- All data is synthetic, generated by the authors' simulators (Sec. 4):
  - Rope: 10,000 episodes.
  - Soft: 50,000 episodes.
  - Swim: 50,000 episodes.
- Each episode has 100 steps, and the split is 90/10 train/test.
- Training systems have 5 to 9 objects. An extrapolation set has 10 to 14 objects.
- The data is not public as a dataset; it is regenerated by the code.

## 4. Evaluation and downstream tasks
- **Metrics:** simulation MSE over 100-step rollouts on 500 trajectories, and control MSE to a target state.
- **Baselines:** Interaction Networks (IN), Propagation Networks (PN), and Koopman with polynomial basis functions (KPM).
- **Simulation (Fig. 3):** the model has the lowest error in Rope, Soft and Swim. IN and PN, adapted by fine-tuning, fail in Rope and Swim, and KPM fails in Rope and Soft. Values are given only as curves.
- **Control (Fig. 4):** QP open-loop for Rope (horizon 40), and MPC with one replanning at step 32 for Soft and Swim (horizon 64). Control error is lower than KPM in all three environments.
- **Koopman-matrix structure ablation (Table 1, Rope).** Simulation MSE is at T=100, control MSE at horizon 40, with extrapolation results in parentheses:

  | Structure | Simulation MSE | Control MSE |
  |---|---|---|
  | Block | 0.105 (0.075) | 0.854 (1.101) |
  | None | 0.117 (0.083) | 1.522 (1.288) |
  | Diag | 0.133 (0.174) | 2.337 (2.809) |

- **Hyperparameters:** a Koopman dimension of 16 per object is best (Fig. 4e), and more identification samples help (Fig. 4d).
- **Downstream tasks:** online system identification, open-loop QP control, MPC, and generalisation to more objects.

## 5. Architecture and techniques
- **Encoder and decoder:** an Interaction-Network-style graph encoder φ maps object states to object-centric Koopman embeddings (m = 32 per object in the main experiments). A graph decoder ψ maps them back to states.
- **Linear dynamics:** g(t+1) = K g(t) + L u(t), with block-wise K and L. Blocks are shared by relation type (Eq. 5–8), so the number of parameters to identify is h·m², independent of the number of objects.
- **System identification:** closed-form least squares on 8 episodes (800 samples).
- **Losses:** auto-encoding + λ1 multi-step prediction + λ2 metric loss, with λ1 = 1.0 and λ2 = 0.3. The metric loss preserves state-space distances in the embedding.
- **Training:** Adam with learning rate 1e-4, batch size 8, 400K to 580K iterations.
- **Control:** quadratic programming in Koopman space, plus MPC.
- **Size:** parameter count not stated.

## 6. Conclusions and future work
- **Authors:** combining deep Koopman operators with graph networks lets the model manipulate ropes and soft robots and generalise to a variable number of components. They hope the work encourages modelling larger, more complex systems (granular materials, cloth, clay) by combining Koopman theory with neural networks.
- **My own observations:**
  - Evaluation is only in low-dimensional 2D simulation with full state access. There are no pixels and no real robot.
  - The block structure needs the relation types to be known in advance.
  - The linear latent dynamics may limit fidelity for contact-rich, discontinuous interactions.
